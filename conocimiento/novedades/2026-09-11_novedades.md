### Enhanced Conversions: atribución sin cookies mediante datos de cliente hasheados

- **Fuente:** PPC Land · **Area:** GA4
- **Implicacion:** Feature de Google Ads que complementa tags de conversión con datos de cliente encriptados para mejorar atribución cuando falla cookie-based tracking. Útil para contextos post-cookie pero requiere infraestructura de datos de cliente y cumplimiento RGPD/privacidad.

- **Fuente:** PPC Land · **Area:** GA4
- **Implicacion:** Nueva métrica de Google Ads cuantifica conversiones recuperadas con setup de datos first-party. Relevante para evaluar ROI de estrategias de consent mode y first-party data, pero no es obligatorio implementar.
- **Enlace:** https://ppc.land/googles-data-strength-uplift-metric-quantifies-first-party-data-in-google-ads/

### Microsoft Conversions API en piloto restringido, sin auto-activación

- **Fuente:** PPC Land · **Area:** server-side
- **Implicacion:** Microsoft lanza su Conversions API server-side (similar a Meta/Google) pero requiere aprobación manual por cuenta, no es acceso abierto. Mantén documentación revisada y solicita acceso si el cliente usa Microsoft Ads; sin embargo, la disponibilidad limitada reduce urgencia inmediata.
- **Enlace:** https://ppc.land/microsoft-gates-its-new-conversions-api-behind-per-account-pilot-approval/

### Regulador de Hamburgo: Ray-Ban Meta glasses exponen datos de terceros sin consentimiento

- **Fuente:** PPC Land · **Area:** consent/privacy
- **Implicacion:** Las gafas inteligentes con cámara podrían requerir consentimiento explícito de bystanders en DACH. Revisar si tus clientes con wearables o campañas que usan datos de bystanders necesitan ajustar politicas de consent mode o legitimizing interest.
- **Enlace:** https://ppc.land/hamburg-regulator-finds-ray-ban-meta-glasses-expose-bystanders-without-consent/
