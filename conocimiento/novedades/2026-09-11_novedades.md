## Relevancia alta (1)

### Microsoft Conversions API requiere aprobación de piloto por cuenta

- **Fuente:** PPC Land · **Area:** server-side
- **Implicacion:** Microsoft lanza Conversions API (server-side) pero acceso limitado a cuentas piloto seleccionadas; no es auto-activable. Requiere solicitar acceso formal y validar elegibilidad de cada cuenta cliente para implementar server-side tracking en Microsoft Ads.
- **Deja obsoleto:** No invalida prácticas previas (UET client-side sigue siendo estándar), pero representa camino preferido futuro para compliance post-cookieless.
- **Enlace:** https://ppc.land/microsoft-gates-its-new-conversions-api-behind-per-account-pilot-approval/

- **Fuente:** PPC Land · **Area:** GTM
- **Implicacion:** Herramienta para integrar datos first-party en productos Google Ads sin código disperso. Revisa si tus clientes pueden beneficiarse de migrar de integraciones GTM+API a Data Manager para simplificar gestión de audiencias y conversiones.

### Enhanced Conversions: atribución sin cookies con datos first-party hasheados

- **Fuente:** PPC Land · **Area:** Meta Pixel
- **Implicacion:** Conocer esta característica de Google Ads es relevante para mejorar atribución en escenarios post-cookie. Evalúa si implementarla en cuentas DACH/ES/UK donde el cookie-matching es limitado, especialmente en conversiones offline o CRM-sourced.
- **Enlace:** https://ppc.land/enhanced-conversions/

### Google lanza Data Strength Uplift para medir impacto de first-party data

- **Fuente:** PPC Land · **Area:** GA4
- **Implicacion:** Nueva métrica en Google Ads que cuantifica conversiones recuperadas por setup de first-party data. Útil para evaluar ROI de estrategias de consent mode y first-party recolección, pero no obliga cambios inmediatos en implementación.
- **Enlace:** https://ppc.land/googles-data-strength-uplift-metric-quantifies-first-party-data-in-google-ads/

### Regulador de Hamburgo: Ray-Ban Meta expone datos de transeúntes sin consentimiento

- **Fuente:** PPC Land · **Area:** consent/privacy
- **Implicacion:** Señal de endurecimiento regulatorio en DACH sobre datos biométricos en wearables y entrenamiento de IA. Monitorea evolución; por ahora no impacta tracking web/app directo, pero presiona a Meta en consentimiento/legitimidad.
